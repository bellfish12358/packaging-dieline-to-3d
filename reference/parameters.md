# 参数、场景与渲染

> 以 `scripts/build_box.py` 顶部常量为准。

## 1. 几何参数

| 参数 | 常量 | 默认 | 说明 |
|---|---|---|---|
| 面片间隙 | `GAP_MM` / `gap` | 2.0 mm | 折轴走缝中线 |
| 纸厚 | `PAPER_T` | 0.5 mm | 350g 白卡；Solidify 向盒内 |
| 倒角 | `BEVEL_W` | 0.5 mm | 3 段；角度限制 40° |
| 折叠角 | `FOLD_DEG` | 90° | 默认值；可用 `--pose` 逐折覆盖（负值=反向，0=不折，>90=回折） |
| 立起方向 | `AUTO_UP_AXIS` / `FLIP_UP` | 自动 | 用最大四片立面之间的折线判断管轴；`--flip-up` 上下翻转 |
| 布景 | `AUTO_SCENE` | `True` | 按包围盒自动取景；`False` = 旧版固定机位 |
| 折痕模式 | `USE_CREASE_BAND` | `True` | True = 窄 V 槽；False = 2mm 明缝 |
| 折槽深度 | `CREASE_DEPTH` | 0.25 mm | 仅 V 槽模式 |
| 折槽缩放 | `BAND_SCALE` | 1.0 | V 槽宽度缩放 |
| 填充缝 | `FILL_GAP` | `False` | 保留缝 |
| 噪点过滤 | 无 | — | 输入前自己删小轮廓 |

### 倒角为什么是 0.5 而不是 0.15

旧文档写 0.15 mm，是早期推算值。最终脚本在 1200 px 出图下用 0.5 mm 才看得到棱边高光；0.15 mm 在远景里几乎不可见。近景特写可以回到 0.2–0.3 mm，别超过纸厚的 60%，否则棱边会塌。

### 折痕模式怎么选

- **成品效果图**：`USE_CREASE_BAND=True`。折痕是一条细 V 槽，外观看不到 2mm 缝。
- **结构说明/教程还原**：`USE_CREASE_BAND=False`。保留 2mm 明缝，能看到板厚断面。
- 两种模式 UV 都不变，随时可切。

## 2. 场景（默认自适应）

`AUTO_SCENE=True`（默认）时按折叠后的包围盒自动布景：目标点 = 包围盒中心，相机沿固定方向（方位角约 27°、俯角约 22°）后退到刚好装下整个包围盒（留 12% 余量），背景/灯位/盒内光按最长边等比缩放，特写按盒高取景。

下面这套绝对坐标只在 `AUTO_SCENE=False` 时生效，是按 **119.4 × 59.4 × 158.9 mm** 的直插盒调的，单位是米。

## 4. 换盒型/尺寸怎么缩放

**默认不用管**：`AUTO_SCENE=True` 时相机、背景、灯位都按实际包围盒算，换尺寸直接跑。只有把 `AUTO_SCENE=False` 时才需要按下面手动缩放。

脚本里的坐标是绝对值（米）。换尺寸后先算：

```text
s = 新盒最长边(mm) / 158.9
```

把相机位置、目标、灯位、背景尺寸都乘以 `s`，焦段不变。

更稳的做法：

1. 从 `report.json` 的 `size_mm` 拿实际包围盒
2. target 设为盒子中心
3. 相机距离取 `2.2 × 最长边`
4. 俯角 20–25°
5. 先出 640×640 小样，再出 1200

宽扁盒（长宽远大于高）不要只按最长边，先看构图再微调。

## 5. 调参顺序

1. 先验几何（clay）：面片、法向、闭合、穿插
2. 再定折缝：`USE_CREASE_BAND` → `CREASE_DEPTH` → `BAND_SCALE`
3. 再定纸感：`PAPER_T` → 倒角 → 纸纹
4. 最后布景：相机 → 主光 → 补光/轮廓光 → 背景
5. 一次只动一个参数，每次先出 640×640 小样

## 6. 本机实测基线

## 8. 逐折角度与姿态（`--pose`）

逐条覆盖折角，用来做半开盒、开盖 45°、插舌回折：

```powershell
blender -b -P scripts\build_box.py -- "刀版.svg" "out_open" --pose "8=-90,9=-90,10=0,11=175"
```

- 序号是 `<g id="fold">` 里 `<line>` 的先后顺序（从 0 开始），`report.json` 的 `split_log` 每条都带坐标；
- 角度相对父面片：`0` = 共面，`90` = 垂直（默认闭合），`180` = 完全回折；
- **负值 = 反向折**，用来把防尘翼翻到盒外；
- 正负号仍由「子面片重心向下」规则决定，`--pose` 只改角度大小和朝向。

`--pose` 不解决穿模：相邻面折到 0°/180° 时纸厚会互相插入，实际给 175° 或留 2–5° 更稳。

## 9. 朝向：`up` 与 `--flip-up`

脚本用「面积最大的 4 片立面之间的折线方向」判断管轴，再决定绕哪根轴立起来：

- 管轴 = 刀版 y → 绕 X +90°（旧版行为）
- 管轴 = 刀版 x → 绕 Y −90°（管轴横着画的刀版）

`report.json` 里有 `up: {axis, rot, confidence, note}`。`confidence` 接近 1 表示判断干净；低于 0.9 会退回旧版并告警。

自动判断朝上的那一端不合意时，加 `--flip-up`；它只翻上下，不改变旋转轴的判断。
